# Белка‑путешественница

3D‑игра в браузере: белка‑летяга проходит путь длиной в один день — от родного дуба через берёзовый луг,
речную долину и сосновое предгорье к Древнему кедру на снежной вершине. Время суток меняется по мере продвижения.

Вся графика процедурная и генерируется при запуске: PBR‑текстуры (земля, кора, листва, камень, снег)
запекаются на GPU, ландшафт и лес строятся из шума, мех белки — shell‑рендеринг, летательная перепонка раскрывается в полёте.

## Запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:5173 (нужен браузер с WebGL2).

## Управление

- **W A S D** / стрелки — бег, **Shift** — спринт
- **Пробел** — прыжок; удерживать в полёте — расправить перепонку и планировать
- **Мышь** — камера (клик по экрану захватывает курсор), **колесо** — приближение, **Q** — повернуть камеру
- Бежать в ствол или **E** рядом с деревом — карабкаться; на стволе **W/S** вверх‑вниз, **A/D** вокруг, **Пробел** — спрыгнуть
- **M** — звук, **Esc** — пауза

Собирайте жёлуди на тропе и золотые жёлуди на макушках деревьев. Прогресс сохраняется автоматически.

## Лакомства и зверушки

В каждом биоме спрятаны лесные лакомства (белые грибы, дикие яблоки, орехи, шишки, брусника), а у тропы
ждут зверушки — ёжик, зайчиха, сойка, бурундук и медвежонок. Над каждым висит пузырь с тем, чего он хочет:
найди нужное лакомство и нажми **E** рядом, чтобы угостить. Инвентарь — в левом нижнем углу.

- `/?debug=textures` — просмотр всех запечённых текстур (`&only=grass,rock`, `&n=1` — карты нормалей)
- `/?debug=squirrel` — белка на поворотном столе (клавиши 1–5 переключают позы)
